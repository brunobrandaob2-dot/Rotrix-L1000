Dá para fazer um app “container”?

Sim, como um único programa instalável.
  • Base: o Handy é código aberto (licença MIT, feito em Tauri + Rust + React). Pode ser copiado e modificado, mas com nome e logo próprios: a marca Handy não é aberta.
  • Dentro dele: voz, roteador, máscaras, formatador, fila do Radius e IA. O roteador entra como está e depois pode ser reescrito em Rust.
  • Docker não serve para o posto de laudo (microfone, atalhos globais, colar em outro programa). Se virar produto, entra só no servidor: contas, licenças, banco compartilhado.
